# Compliance Landing Page

A responsive landing page developed from a Figma design using HTML5 and CSS3.

## Live Demo

https://compliance-landing-pages.netlify.app/

## GitHub Repository

https://github.com/Ravikiran9988/compliance-landing-page

## Features

* Responsive design for Desktop, Tablet, and Mobile devices
* Clean and semantic HTML5 structure
* Modern CSS3 styling
* Mobile-friendly layout
* Pixel-perfect implementation based on the provided Figma design
* Hero section with call-to-action buttons
* Compliance information section with feature cards

## Technologies Used

* HTML5
* CSS3
* Flexbox
* Media Queries
* Google Fonts (Roboto)

## Setup Instructions

1. Clone the repository:

```bash
git clone https://github.com/Ravikiran9988/compliance-landing-page.git
```

2. Open the project folder.

3. Run `index.html` using Live Server or open it directly in a browser.

## Assignment Details

This project was created as part of a Figma-to-HTML/CSS frontend development assignment. The objective was to convert the provided Figma design into a responsive static webpage while maintaining design consistency across different screen sizes.
